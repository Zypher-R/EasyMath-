Basic Operations

For addition, simply add the two numbers together. For subtraction, subtract the second number from the first. Multiplication is repeated addition, and division is splitting into equal parts.

Algebra

Linear equations: Isolate x by moving terms to opposite sides.
Quadratic equations: Use the quadratic formula: x = [-b ± √(b²-4ac)] / 2a

Polynomials

Adding/Subtracting: Combine like terms.
Multiplying: Use the distributive property (FOIL method for binomials).
Factoring: Look for common factors or use patterns like difference of squares.

Trigonometry

Sine: opposite/hypotenuse
Cosine: adjacent/hypotenuse
Tangent: opposite/adjacent
Inverse functions return angles for given ratios.

Geometry

Circle: Area = πr², Circumference = 2πr
Triangle: Area = ½ × base × height
Rectangle: Area = length × width, Perimeter = 2(length + width)
Sphere: Volume = (4/3)πr³, Surface Area = 4πr²
